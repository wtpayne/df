Product Ideas:
==============
These are things that we could implement in a timeframe of a few months.
Each product can stand on its own, and hopefully generate an income stream.
The larger vision involves the integration of the products to one big framework.

1. Eva: Enhanced Virtual Argumentation
-----------------------------------
* Evaluate arguments, create a summary of beliefs per speaker in real time
* Give topic suggestions, things to think about
* Decision making aid via rhetorical super-open questions
* Transcribe call using whisper, visualise summaries in real time
* Detect core disagreements, generate questions to consider to resolve those disagreements

2. Semantic Web Search Engine and Browser
--------------------------------------
* Create a big "hub". A true front page of the internet. With all the things that exist online categorised by LLMs.
* Custom Crawler - or import data from existing internet data
* Custom Indexing - use LLMs and embedings to cluster web pages
* Instead of ranking for search terms, we just display the clusters with LLM generated labels
* A user can browse through the catalog, and view information - adverts are removed and we just keep the content.
